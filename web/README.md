# 抖音音频提取

在 Windows 上打开 `start.cmd`，然后在浏览器访问 [本地网页](http://127.0.0.1:8765)。需要 Python 3.10 或更新版本、已安装的 Google Chrome，以及网络连接。第一次启动会在项目目录的 `.venv` 中安装 Python 依赖。关闭命令窗口即可退出。

点「填入示例」可以试用，也可以从抖音 App 复制链接后粘贴。点击「提取音频」，等页面显示试听和下载入口。

- `index.html` 提供输入、状态、试听和下载。
- `POST /api/audio` 接收 `{"url":"抖音分享链接"}`。后端运行 `extract_audio()`，返回这次生成的音频文件。
- 当前支持包含作品与原声信息的抖音 App 视频分享链接。提取结果来自平台提供的独立音轨或对应原声。
